# 🧠 Brain Tumor MRI Classification

## 📌 Overview

This project uses **Deep Learning and Transfer Learning** to classify brain MRI images for brain tumor detection.

A **ResNet50** model pretrained on ImageNet is used as the backbone, with transfer learning applied to classify MRI images into different tumor categories.

## 🎯 Objective

To build an image classification model that can automatically identify brain tumor categories from MRI images.

## 🛠️ Technologies Used

- Python
- TensorFlow
- Keras
- ResNet50
- Transfer Learning
- Convolutional Neural Networks (CNN)
- NumPy
- Matplotlib
- Google Colab

## 🧠 Model

**ResNet50 + Transfer Learning**

The pretrained ResNet50 network is used to extract meaningful image features, followed by a classification layer for predicting the tumor category.

## 📂 Dataset

The notebook supports a ZIP-based dataset structure containing MRI images and the required training data files.

## 🔬 Project Workflow

1. Upload and extract the MRI dataset
2. Prepare and preprocess the images
3. Load the pretrained ResNet50 model
4. Apply transfer learning
5. Train the classification model
6. Evaluate model performance
7. Generate predictions

## 📊 Results

The notebook includes model training, evaluation, and prediction steps for brain MRI classification.
